# 问题排查

## 设备没有连接

先确认USB连接，再检查是否有StreamDock、其他WebHID页面或另一个原生桥接占用设备。桥接进程运行不代表设备已经就绪；查看控制页中的设备状态。不要通过关闭Windows安全功能来绕过安装错误。

## 画面异常

停止显示更新并记录现象、设备型号/固件、发生前的操作。可用纯色检查页对比黑、白、方框。开发期间曾出现扫描线错位，使用SDK默认JPEG参数并断电重连后恢复；这不是对所有设备有效的修复保证。不要反复提高刷新率尝试恢复。

## 灯光变暗或完成不变绿

Micro自动调暗不代表任务未分配。绿色表示完成且有未读更新；当前已查看会话可能回到空闲。桥接跟随主机状态，不自行创建完成或已读状态。

## 提交问题

提供版本、复现步骤、预期/实际结果，以及必要且脱敏的日志。不要提交整个便携目录、个人配置、证书、凭据或聊天内容。安全问题按SECURITY.md处理。
