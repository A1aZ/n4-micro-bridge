# 同一机器人，原生状态表情

## 当前外观调整

按用户选择恢复最初六款像素角色的美术风格，但继续按原生状态颜色族选择，绝不按槽位号选图。映射以 assets/themes/status-art.json 为准：空闲紫色闭眼、工作青色、完成绿色欢呼、待输入琥珀、错误珊瑚红、未亮或未知灰色。主机状态色带保留原始RGB；角色配色仅为美术设计。以下单轮廓机器人说明为历史版本。

像素主题不再按AG00–AG05分配六种不同角色。固定01–06编号标识槽位，同一96×96像素矢量机器人按主机颜色族选择表情。

白/低饱和度：普通空闲表情；蓝：专注工作；绿：笑脸和胸前小勾；琥珀：等待输入；红：叉眼；熄灭：弱化休眠表情。其他颜色使用中性机器人。熄灭也可能来自自动调暗，不能据此断言任务未分配。

颜色族分类只用于显示，不生成任务状态事件，不锁存完成或读写已读状态。原始RGB始终保留在状态色带。选中脉动不影响表情分类。任意自定义颜色不保证能推导官方状态，无法识别时不猜测。

图标由 scripts/build-status-robots.cjs 生成，24格矢量整数放大为96像素，运行时1:1显示，无额外图像缩放。官方默认JPEG、内存传输和刷新间隔均未改动。
