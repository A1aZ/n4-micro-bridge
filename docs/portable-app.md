# Mirabox 便携控制中心

## 系统托盘行为（当前版）

启动服务后不自动弹出网页；通过主窗口或托盘菜单的“打开控制页”手动进入配置与诊断。

右上角 × 隐藏窗口到系统托盘，不停止服务；— 最小化到任务栏。
双击托盘图标恢复窗口。右键菜单提供打开主窗口、打开控制页、停止服务、退出。
明确选择退出才清理本启动器的进程；Windows关机/注销也正常清理，不拦截为隐藏。
第一次关闭有托盘提示，图标可能在右下角 ^ 隐藏图标列表内。
启动步骤进行中选择退出会等待当前步骤结束并取消后续启动，再清理退出。
下方较早版本所述“关闭窗口停止服务”已由本节取代。

双击 Mirabox.exe，再点“启动全部”。控制页、N4 原生连接、Micro Relay 一起启动；关闭窗口或点“停止全部”会清理本启动器及其子进程。不自动重放失败的输入操作。

整个文件夹需要一起保留，不能单独移动 EXE。无需另外安装 Python、Node 或运行 PowerShell。需要 Windows x64 和 .NET Framework 4.x（当前机器已具备）。请解压到可写目录，不要放在 Program Files 或直接从压缩包运行。

首次切换请先关闭旧版 Relay 命令窗口，并在旧控制页断开 N4；StreamDock 也应退出。启动器不会强制结束旧服务或其他软件。新控制页使用 18792 端口，与旧版区分；浏览器 WebHID 连接需要手动断开。

配置保存在本文件夹 data/config.json，日志在 logs。重新打包时请保留自己的配置。虚拟 Micro 驱动须预先安装；此程序不安装驱动、不修改证书或启动安全设置。

此开发版 EXE 未签名。只运行来自本项目可信路径的构建。若服务失败，查看日志后重试；服务启动不等于真实 N4 已成功连接，以控制页状态为准。
