# 遵循 Micro 原生状态

官方说明：https://learn.chatgpt.com/docs/features/codex-micro

白＝空闲；蓝＝工作中；绿＝完成且有未读更新；琥珀＝需要审批或回复；红＝错误；熄灭＝未分配聊天。选中的聊天按状态颜色脉动，不能把脉动当作工作中。自动调暗也可能使灯熄灭，不能仅凭暗屏断定所有任务未分配。

实现仅使用现有 Micro v.oai.thstatus 灯光字段。不另读任务API、不依据计时猜测完成、不维护本地完成或已读锁存。原始颜色直接用于按钮底部固定色带，外框继续按收到的灯效显示。主机切换颜色时立即跟随，关闭灯效或亮度为零时色带弱化。

保持原生尺寸图标、官方默认JPEG编码、内存传图、批次刷新及已有节奏。网页六状态按钮是明确标注的模拟视觉通知，不触发按键；实际应用消息可以覆盖它。
